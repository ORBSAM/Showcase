Project: NO USB!

Custom TCP Communication Tool

Mission Brief

A simple TCP tool that communicates between two different platforms... and sends files of the user's choosing. Both machines must be running on the same network, and have a port available.

Key Highlights

01. The Core Challenge

What was to be tackled? Well, since I have two laptops... I needed a simple way to have a universal tool (aside from a USB) to send reasonably sized files between the two.

02. The Solution & Architecture

C++. Loved by Linux and... well, functions on Windows. Using CMake and other universal GUI libraries, I was able to craft a program that allowed me to communicate to my other machine... if it was on the same network.

03. Key Takeaway / Future Plans

It was fun trying to get this to work; learning how DearImGui worked, and how it is kinda better than wxWidgets... I think I might avoid doing lower-level GUI programming in the future unless it is absolutely necessary. One thing I'd like to note is how annoying how Wayland calls windows; literally made it near impossible to open up a file prompt.
On another note, this project complements well with my Intro to Networks class. Hope I can understand how sockets work like this in-depth at a later time.
