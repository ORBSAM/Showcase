Language Log: C, C++, and C#

C Family overview

C is objectively better than a lot of languages, mainly in terms of speed and efficiency. Only real issue is the lack of libraries and true flexibility... which is where C++ comes in. C# is just kinda there because Microsoft couldn't get Java ¯\(ツ)/¯. By no means a bad language... it's main usage appears to be .NET (or, alternatively, you can use Visual Basic ⛈)

Code Projects

Most of the programs I did in C were back in my second year classes at RIT. My C++ projects are still W.I.P, and use various libraries from the web.

Game of Life

Game of life but trees and burning in C. I wish I kept the source code for this. I might reconsider doing it for C# just for the novelty of it, and have it as an endless screensaver in C++/C perhaps. One funny thing I found on F-Droid was a cute screensaver that takes the Game Of Life and updates it every so often.

TCP Receiver

Using a whole bunch of C++ libraries and DearImGui, I made a simple TCP receiver and sender that... receives and sends small files.

Metadata Scraper/Remover

Removes or modifies the metadata of a user-selected file. Uses exifdata and other libraries. wxWidgets is not really easy to setup and use on Windows... will consider trying this on Linux instead in the future.

Screensavers

Already made a few screensavers in C#, one major one that includes editing is Mental States. I made a lesser version called "Narcolepsy" for a project in Biology. Currently crafting another for Linux... as Wayland is really annoying about it for some reason.

Mental States
Simple screensaver that utilizes C# to display various bouncing balls across your screen. Oh, and you can click to make a shockwave. All the colors are able to be edited via a pop-up menu.

"Neofetch" Linux Screensaver

A dabble into the world of Linux programming and dealing with the plentiful amounts of GUI libraries... also finding a neat workaround to Wayland's bad idle detection system.
